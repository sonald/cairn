03 · Keep your bearings

Detours never cost you the way back.

Reading code isn’t linear. Cairn keeps every branch of your exploration and brings it all back when the project reopens.

  1. ORIENT

    Jump anywhere

    ⌘P opens a file by name. Prefix @ for symbols in the file, # for the project, : for a line, > for a command.

  2. RETRACE

    A trail with branches

    ⌥⌘T shows the route you took. Restore an earlier node without discarding the sibling branches you explored.

  3. MARK

    Exact bookmarks

    ⌘⇧M anchors a line to its snapshot, with a note. Drifted content is labeled and re-anchored only when you say so.

  4. LEAVE A CAIRN

    Freeze a Reading Set

    Freeze results or a whole path. The Reading Set keeps its source and evidence, ready after a restart — next week, or for the next reader.

Leave no trace

Not an editor.
On purpose.

Point Cairn at code you don’t trust yet. It reads; it doesn’t write, build, fetch or check out.

  • save filesread-only reader
  • run build scripts or proc macrosdisabled in Safe Reading Mode
  • reach the networkdenied by default
  • git checkoutsnapshots are virtual
  • forget where you weretabs, trail and Reading Sets restore
