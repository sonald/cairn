# Cairn homepage

Static HTML, CSS and a small vanilla `script.js` (the scroll tour, the interactive reader and the snapshot demo); no build step or runtime dependencies. The tour's screenshots are `site/assets/tour-*.webp`; `og.png` is a 1200×630 crop of the reader one.

## Preview

From the repository root:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory site
```

Open http://127.0.0.1:8765.

## Publish

In the repository's **Settings → Pages**, select **GitHub Actions** as the source. The `pages.yml` workflow publishes `site/` to the configured custom domain, [cairn.sonald.me](https://cairn.sonald.me/), when changes to the site reach `main`.

Workflow configuration follows [GitHub's Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Demo data

The interactive reader and snapshot timeline use real results from [sonald/knuth-rs](https://github.com/sonald/knuth-rs) at `fac975a`: callers, resolutions and certainty from `codeinsight callers`/`resolve`, Exact targets from `codeinsight exact-def` (rust-analyzer, Safe mode), and the `HookContext` history from `git show <commit>:crates/knuth-agent/src/hooks/types.rs`. Re-run those commands against a clean checkout of that commit when updating the data.

The tour screenshots show the packaged 0.5.0 app reading a clean clone of knuth-rs at `fac975a` (branch `main` pointed at that commit), Light theme and English UI via launch arguments: `open -a Cairn.app <clone> --args -AppleLanguages '(en)' -reader.theme Light`, captured with `screencapture -o -l <window-id>` (no window shadow; the page adds its own) and converted with `cwebp -q 82 -resize 1600 0`. Without JavaScript, or below 860 px, each screenshot sits under its own step.

- `tour-reader`: `crates/knuth-agent/src/harness.rs`, Callers of `after_tool_use`.
- `tour-overview`: the same file in Overview, with Jev scores.
- `tour-ask`: an AI panel answer from a real model (the one configured in Settings → AI at capture time).
- `tour-guide`: the Guide panel for a knuth-rs file, generated by the same model.
- `tour-compare`: `crates/knuth-agent/src/hooks/types.rs` at `864d216` compared with the working tree.
