选中一个符号后在这里显示它的声明。

组织方式

  • 种类：函数、方法、结构体/类、枚举、Trait/接口、类型别名、impl、模块、常量/静态十个组，标题带计数，默认折叠。
  • 类型行可展开：先列字段，再列同文件的 impl；别的文件里的同名 impl 只在这个名字在单元内唯一时合并进来并打“按名称合并”标记（看 Entry）。raft::log::Log 与 storage::bitcask::Log 重名，所以各自只挂同文件 impl，其余留在 impl 组。
  • 方法在“方法”组里平铺（所属在名称前），展开类型或 impl 时再次出现，指向同一个 facet。
  • 模块：单元 → crate → mod 链（含内联 mod tests）；到不了 crate 根的文件进“未挂载的文件”。Python 按目录路径；TypeScript 按目录加文件。

过滤与状态

  • 文字过滤用 # 同一套匹配（前缀、缩写、子序列），容器只要有匹配的后代就保留并自动展开，自身不匹配时灰显。
  • 仅公开是一个开关：受限（pub(crate)、protected）和私有一起隐藏；trait 方法签名“不适用”视为通过，impl 块只在有通过的方法时灰显保留（impl Key 不会留下）。行首记号：● 公开 ◐ 受限 ○ 私有。
  • 范围“当前目录”取焦点阅读区文件所在目录，含子目录。
  • 索引中显示占位；快照变化后旧树置灰并禁止跳转，重建后按 (path, contentID, nameRange) 恢复选中。

交互

  • 单击 / ↑↓：预览标签打开并闪烁声明名，焦点留在列表，Context 跟随。⏎ / 双击：保留打开，焦点交给阅读区。
  • ←→ 折叠/展开；过滤框 ↓ 进列表；Esc 先清过滤文字，再把焦点还给阅读区。
  • 右键：打开、在右侧打开、查看调用者/被调用者/引用/实现、高亮此名称、在文件树中显示、复制限定名。
  • ◎ 定位当前符号：按 Context 指向的符号（没有则光标所在声明）展开并选中；被过滤隐藏时只提示，不改过滤。面板不自动跟随光标。
  • 默认 ⌃⌘S 显示面板并聚焦过滤框；组织方式、种类、仅公开、范围按应用级记忆。

“?”列出不会出现的声明：Rust 枚举变体与宏、Python 模块级变量；TypeScript 的 interface / type / enum 在 D1 采纳前也不出现。
