## 真实流程发现的问题（修复后仍须重验）

1. 字体菜单多个不同PS字体共用相同displayName，Fira显示5个“Fira Code Light”，JetBrains显示多个“Regular/Italic”。不同选择无法辨识，且Regular被称为Light。修复方向：冲突组显示稳定PS name。
2. 主 Reader纯鼠标拖选结束时选区被清空。调用链为 `mouseDown → super → clickHandler → activate → setSelectedRange`。键盘及Reading Set能保留选区，不能据此把主Reader鼠标验收算通过。修复方向：原生非空选区完成后走selectionHandler，不再执行普通点击激活。
