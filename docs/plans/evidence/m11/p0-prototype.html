§2 折叠柄（gutter 展开/收起箭头）

合同（§3.10）：needsRuler = lineNumbers || 有 diff || 有可见折叠区，折叠列计入 rulerThickness。行号关 + diff 空 + 有折叠区时 ruler 仍显示。hiddenLineCount < 2 不画柄。⌥ 点击递归同级。

§3 阅读高度档控件位置 — Full / Structure / Overview

合同（§3.7 / §3.8）：快捷键 ⌥⌘0/1/2 + View ▸ Folding 五项菜单是硬要求。P0 要定稿是否额外加常驻可见控件。三档：Full（无折叠）/ Structure（declaration body + imports + cfgTest）/ Overview（再加 container，只留 depth 0 声明头）。

§4 Palette 浮层位置 — ⌘P / ⇧⌘P / ⌘T / ⌘L 统一入口

合同（§3.12 / §3.13）：五模式同一输入框，前缀切换。模式：（无）文件 / > 命令 / @ 当前文件符号 / # 项目符号 / : 行号。每模式最多 20 条。P0 定浮层位置。

§5 常驻作用域头 — 定稿呈现（§3.15）

合同（§3.15）：顶部钉住至多 2 层，kind/name 来自 outlineFacets。最小包含 facet + kind 兼容关联。无包围声明时整条不占位、不留空条。caret 在 JoinSet::spawn_on（join_set.rs:88，位于 impl Runtime 内的 fn spawn_on body 中）。

§6 Reading Set header · AT CAPTURE Inspector · 三动作 — 基于 M10 D6

合同（§3.20）：Reading Set 是冻结、可恢复的非文件 tab；每段显示 role / path:line / badge / caveat·scope chip / provenance chip。三动作：打开完整文件 / 扩大上下文 / 查看证据，含 disabled 态。AT CAPTURE Inspector 是冻结态 Resolution Inspector，标题带 AT CAPTURE，availability/environment 明确标 capture-time，audit rows 用稳定 provenance（commit / worktree captured / dependency captured），绝不显示 runtime UUID。

§7 Folding 菜单文案 · imports/cfgTest 归档 — 定稿呈现

imports/cfgTest 归档定稿（§3.7 待 P0 定项）：imports 与 cfgTest 归入 Structure 档（与 declaration body 同档自动折叠）。理由：import 区和 #[cfg(test)] mod tests 在"看结构"时都是想收起的噪声，与 declaration body 同级。.block/.comment/.attributes 保持手动 only。
