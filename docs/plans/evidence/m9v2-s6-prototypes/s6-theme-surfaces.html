主题表面统一 — 整窗对照原型

目标（§1.4）：在 Light / Dark / SI Classic 下，侧边栏 · Reader · Relations · Context 看起来属于同一个应用——同主题内背景、选中色、分隔线、文字层级协调。做法（§3.4）：把三区的 surface / selection / header / divider 色并入 ReaderTheme（每主题一组），整窗 titlebar、status bar 与内容区共享同温度 chrome，替换对系统材质色的依赖； view 层不留裸 RGB。

现状的割裂来源：Reader 有四套主题、侧栏用 NSVisualEffectView(.sidebar) 系统冷灰、 Relations 用 .windowBackground 系统色——于是 SI Classic 的暖纸色 Reader 旁边贴着一条冷灰系统侧栏， 最割裂。下面每个窗口把三区统一到同一套暖/冷表面：Reader 内容色不变，侧栏/Relations/Context 取同温度的 chrome 面。 此稿已带上 S2=B 蓝环主选中（第 3 行 self.recursive）与 S5=A Relations 排版。
