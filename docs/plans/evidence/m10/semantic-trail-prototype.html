设计决策（映射到 v1.3.1）

  • 分叉而非覆盖 §3.11–3.12：spawn 分叉点保留 JoinSet::spawn_on 与 LocalSet::spawn_local 两支。NavigationRecord.trailNodeID 让 Back 能精确回到"这一个 spawn"而非按 path/offset 猜。
  • cause 标注的边 §3.11：每条边带 NavigationCause（calls / called by / definition / implementation / reference）。只有显式语义导航进 Trail；滚动、outline 自动跟随、tab 切换不进（policy.recordInTrail）。
  • snapshot 分段 §3.12/§3.14：跨 snapshot 边界画分段线。commit 节点精确恢复；旧 worktree 节点 best-effort、显 "replayed against current worktree"。
  • 冻结快照 vs 当前态 §3.13：LocalSet::spawn_local 导航当时冻结为 Inferred · method name only · verifying…；exact 后来升级，currentExplanationID 读到 Inferred · trait bound · not corroborated。两个都存——审计快照不变，当前解释可更新。Store 只存物化数据、无 live ref。
  • 节点复用 epistemic badge：Trail 节点直接挂原型 01 的三值 badge，视觉语言一致。
