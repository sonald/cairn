## 1. 背景

快捷键越来越多。类型直达又要新增 ⌃⌘J、⌘⇧+单击 和三条上下文窗口命令，需要一个统一管理、定义快捷键的地方。

## 2. 现状（2026-09-30 核实）

- **菜单快捷键**：约 45 个，全部写死在 `makeMainMenu()`（`Sources/CodeInsightApp/CodeInsightApp.swift:11673` 起），逐个 `NSMenuItem(keyEquivalent:)` 加 `keyEquivalentModifierMask`。没有集中定义，也没有冲突检查。
- **一条命令多组快捷键**：“后退”有 ⌃⌘← 和 ⌘[，“前进”有 ⌃⌘→ 和 ⌘]。第二组用的是隐藏的菜单项（`isHidden = true` 加 `allowsKeyEquivalentWhenHidden`，`CodeInsightApp.swift:11905` 起）。
- **重复定义**：⌘P 在菜单“快速打开”里定义了一次，在工具栏弹出菜单里又定义了一次（`MainWindowController.swift:2664`）；⌘, 同样（`MainWindowController.swift:2686`）。
- **不走菜单的快捷键**：⌥Z（自动换行）由一个按键监听单独拦截（`handleWrapKeyEquivalent`，`CodeInsightApp.swift:11550`），因为只按 ⌥ 时键入的字符会变（⌥Z → Ω），菜单匹配不上。
- **鼠标修饰键手势**：阅读器里 ⌘+单击 跳转、⌥+单击 显示文档，写死在 `MainWindowController.swift:4666`；上下文窗口迷你阅读器里 ⌘+单击 打开，写死在 `MainWindowController.swift:7388`。
- **面板内按键**：命令面板、搜索、书签、关系窗口里的方向键、回车、Esc 由各自的 `keyDown` 或按键监听处理，共 6 处。
- **命令面板**：`>` 模式的命令列表直接读 `NSApp.mainMenu`（`PalettePanel.swift:1063`），会跳过隐藏项。所以菜单项的快捷键从定义表来之后，命令面板自然一致。
- **设置窗口**：SwiftUI `TabView`（`ReaderSettingsWindowController.swift:267` 起），现有“阅读器”“精确分析”等页，没有快捷键页。
- **macOS 自带的“App 快捷键”**：按菜单标题匹配。Cairn 有中英两种界面语言，换语言后映射会失效；它也管不到鼠标手势和 ⌥Z 这类监听。所以不能靠它。

## 3. 需求

### K-R1 集中定义表

- **K-R1.1** 每条命令只在一处定义：稳定 ID（例如 `navigate.back`）、所属分组（与菜单一致）、本地化标题、默认绑定列表（可以是 0 组、1 组或多组）。
- **K-R1.2** 绑定分三类：
  - **键盘**：修饰键集合加一个键。
  - **鼠标手势**：修饰键集合加“单击”，只用于阅读器。
  - **固定键**：面板内的方向键、回车、Esc。只读，登记在表里只为了在设置页里展示。
- **K-R1.3** 菜单项的 `keyEquivalent`、隐藏的第二组快捷键、⌥Z 这类监听、阅读器的手势分发，全部从定义表生成或查表。代码里不再出现写死的快捷键字面量；工具栏弹出菜单里重复的 ⌘P、⌘, 合并为引用同一条命令。
- **K-R1.4** 数据模型分两层：“方案”（现在只有默认方案）加“用户覆盖”。覆盖只保存与默认值不同的命令；删掉覆盖就恢复默认（Q19）。数据可以序列化（为以后导入导出留口，Q15），但这一轮不做导入导出。
- **K-R1.5** 定义表放在不依赖 AppKit 的模块里（CI 禁止 core 和 model 目标引入 AppKit），和 `NSEvent.ModifierFlags` 的相互转换放在 App 层。

### K-R2 规则

- **K-R2.1** 键盘绑定至少带 ⌘、⌃、⌥ 之一；单独 ⇧ 或不带修饰键会被拒绝，提示“需要带 ⌘、⌃ 或 ⌥ 之一”。
- **K-R2.2** 锁定的系统通用组合：⌘Q、⌘W、⌘C、⌘V、⌘A、⌘X、⌘,。占用它们的命令不能改键，别的命令也不能录成这些组合（Q17）。
- **K-R2.3** 冲突：录到已被占用的组合时，在行内提示“⇧⌘F 已分配给「在项目中查找…」”，给出“替换 / 取消”（K2=A）。替换后，原来那条命令失去这组绑定（没有别的绑定就显示“未设置”），两条命令都标记为已修改。
- **K-R2.4** 鼠标手势至少带一个修饰键（单独点击留给定位光标）；手势之间也做冲突检查。
- **K-R2.5** 默认定义表本身不能有冲突，CI 用测试保证（Q17）。
- **K-R2.6** 修饰键按 macOS 的标准顺序显示：⌃⌥⇧⌘。

### K-R3 设置页

- **K-R3.1** 设置窗口新增“快捷键”页，图标用 `keyboard`。
- **K-R3.2** 布局：单列列表，按菜单分组，分组标题吸顶（K1=A）。每行显示：修改标记（圆点）、命令标题（新命令带“新增”小标）、快捷键键帽（多组并排）、悬停时出现的“+”（再加一组）、已修改时出现的“恢复”。锁定行显示锁形图标；固定键的键帽是只读样式。
- **K-R3.3** 录制：点键帽进入录制，键帽显示“按下组合键…”，下方提示“Esc 取消 · ⌫ 清除这一组”。按下组合键后立即校验（K-R2）并生效。鼠标手势行点键帽后出现虚线录制区，提示“按住修饰键并点击”。
- **K-R3.4** 顶部：搜索框（匹配命令标题、分组名、快捷键文字），“按键搜索”按钮（按下一个组合键，列出用到它的命令），筛选胶囊“全部 / 已修改 N”。
- **K-R3.5** 底部：说明“快捷键对所有窗口生效。面板里的方向键、回车、Esc 固定不可改”，加“全部恢复默认”按钮。
- **K-R3.6** 改动立即生效：所有窗口的菜单、手势、命令面板（Q18：面板每条命令右侧显示当前快捷键）。
- **K-R3.7** 快捷键是全局偏好，所有窗口共用，不按项目区分。

### K-R4 类型直达带来的新条目

K0 不登记这些条目，免得设置页里出现还没有功能的命令。类型直达计划的 P1（前两条）和 P3（后三条）在实现功能的同时登记。

| ID | 标题 | 默认 |
|---|---|---|
| `navigate.typeDefinition` | 跳到类型定义 | ⌃⌘J |
| `reader.gesture.typeDefinition` | 跳到类型定义（鼠标） | ⌘⇧+单击 |
| `lens.trackSymbol` | 跟踪光标下的符号 | 未设置 |
| `lens.trackEnclosing` | 跟踪所在函数 | 未设置 |
| `lens.togglePin` | 固定 / 取消固定 | 未设置 |

## 4. 非目标

- 不预置第二套键位方案（例如 Source Insight 风格、Xcode 风格），只留数据模型（Q19）。
- 不做快捷键速查浮层（Q18：命令面板就是速查）。
- 不做导入导出（Q15）。
- 面板内导航键不可改（Q16）。
