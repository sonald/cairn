# 产品行为与边界

Cairn 是 macOS 原生只读代码阅读器；CodeInsight 是 Swift package 和模块名。它帮助用户阅读陌生项目、理解符号与关系、比较 Git 快照，并保留阅读现场。当前语言分析支持 Rust、Python、TypeScript/TSX。

## 只读与分析信任

Cairn 不编辑源码，不执行 Git checkout，也不替项目安装依赖。读取工作区时捕获源码，读取 commit 时直接读取 Git 对象；切换历史不会改变工作区。

Exact 分析由本机安装的 rust-analyzer、Pyright、typescript-language-server 提供。默认 Safe 模式禁止网络，Rust 构建脚本和 proc macros 关闭。缺少工具、离线依赖或沙箱时仍可语法阅读，并明确显示精确分析不可用的原因。

用户显式信任项目后，Rust 分析可以开启构建脚本/proc macros；沙箱仍禁止网络，允许分析缓存及项目 `target` 目录写入。因此“只读”不是承诺所有受信任分析子进程完全没有写入。撤销信任会停止并重建受影响项目的分析；清理共享物化缓存前停止 Exact 工作。

## 项目、快照与窗口

- 一个项目对应一个窗口。再次打开同一实际路径（含符号链接或 `.`/`..` 别名）激活现有窗口；新项目优先使用空白窗口。
- 每个窗口拥有自己的项目、索引、Exact 会话、标签、导航历史和布局。信任、书签与物化缓存是应用共享资源。关一个窗口不应关闭其他项目。
- 文件树显示常规非符号链接文件。工作区默认跳过 `target`、`node_modules`、`.build`、`venv`、`.venv`、`__pycache__`、`dist`、`build`，`.git` 始终跳过（列表见 [ProjectPathRules.swift](../Sources/CodeInsightCore/ProjectPathRules.swift)）。工作区捕获不按 `.gitignore` 筛掉文件；commit 的 tracked 文件既不因 `.gitignore`，也不因默认跳过目录而消失。
- “文件 → 项目排除规则…”为当前项目编辑排除规则：每行一条 glob（语法同“搜索选项”的路径过滤），`!` 开头表示包含，后面的规则覆盖前面的，因此 `!build/` 可以恢复默认跳过的目录（连同其中嵌套的默认跳过目录）。与 `.gitignore` 相同，被排除目录里的文件不能单独重新包含。被排除的路径不进文件树、不建索引、不参与搜索和关系查询；工作区与 commit 快照都生效（commit 只应用用户规则）。规则只保存在本机应用数据里、按项目实际路径区分，不读取也不写入仓库中的任何规则文件。保存后走 Refresh Index，标签、阅读集、书签、轨迹和布局保留。
- 有规则排除时，文件栏标题右侧显示被排除的路径数（每个被剪掉的分支只计最上层一项），点击列出这些路径并可进入编辑；项目搜索底部同样写明“按项目规则排除 N 个路径”。仍打开着的被排除文件（或经 Exact 跳入的被排除文件）在路径栏显示“已排除 · 不参与索引”，可继续阅读。
- 索引来源的导航要校验目标内容身份。文件已变化时提示刷新索引；刷新重新捕获工作区，同时保留标签、阅读集、书签、轨迹和布局。
- 阅读会话按项目保存。重新打开可恢复文件、位置、标签、前进/后退、轨迹与阅读集；旧 worktree 只能对当前工作区尽力重放，不声称恢复过去的实时文件。
- 清除阅读会话是显式操作。保存失败、较新格式、暂不可读或项目卷离线时不静默覆盖原会话。

## Reader 与导航

单击文件打开可复用的预览标签；双击、Open in New Tab 或 Keep Open 将其保留。恢复的标签是保留状态。`⌘P` 快速打开，查询前缀 `>`、`@`、`#`、`:` 分别选择命令、文件符号、项目符号和行号。本文快捷键均指默认绑定。

主阅读区只读，支持选区、复制、查找、折叠、换行、比较、语法样式及同名标识符高亮。复制始终来自原始源码，不从折叠占位符、连字字形或着色显示文本反向生成。

Full、Structure、Overview 和 Focus Scope 是文件 Reader 的折叠方式，不适用于非源码预览和阅读集。

### 面板布局

窗口左右两侧各有一个面板区。文件、大纲、关系、上下文、搜索结果是面板；阅读区（含分屏和比较）、阅读轨迹条和状态栏不是面板，不移动。同一侧的面板上下堆叠，分隔条可调高度；一侧没有可见面板时收起，阅读区占满。没有底部区域、标签页或浮动面板窗口。

每个面板的标题栏有标题、`⋯` 和 `×`。`⋯` 菜单提供移到左侧、移到右侧、上移、下移和关闭，当前位置做不到的项置灰。拖标题栏可放到任一侧的任意位置：拖动影像只有标题栏，目标侧显示强调色指示线，鼠标在某面板上半部表示放到它前面、下半部表示放到它后面，空白处表示放到末尾；拖动期间空着的一侧显示 72pt 宽的“放到这里”，松手后仍为空则收起。

“视图 → 面板”列出全部面板，勾选表示正在显示。关系（`⌃⌘R`）和“显示/隐藏搜索结果”沿用原命令并移入这个子菜单；文件、大纲、上下文的开关默认无快捷键，可在快捷键设置里绑定。上下文默认跟随自动规则：光标处有可显示内容时出现，没有时收起。面板的 `×`、取消勾选或状态栏 Context 按钮关闭它后不再自动出现，直到再次打开或切换预设；重新打开时即使暂无内容也立即显示，有内容后回到自动规则。

预设 `⌘1`–`⌘4` 只切换显示组合，不改变放置和宽度：阅读 = 文件、大纲；关系 = 文件、大纲、关系；比较 = 文件并打开比较分屏；专注 = 全部隐藏，上下文也不再自动出现。前三种的上下文跟随自动规则；搜索结果在四种预设下都隐藏。切换预设后仍可单独开关面板。关闭比较只关闭分屏，不改变面板显示。“视图 → 恢复默认布局”恢复放置、宽度、高度和显示：左侧文件、大纲（240pt），右侧关系、上下文、搜索结果（300pt），只显示文件、大纲和自动上下文。

布局是应用全局一份，保存每个面板的位置和显示、两侧宽度、面板高度及分屏比例，不按项目或预设区分；各项目窗口读写同一份，已打开的其他窗口不实时同步。分隔条拖动结束、移动或开关面板、窗口关闭时保存。启动和恢复阅读会话都不改变面板的显示与放置，单独开关的面板在重启后保持；会话只记住最后选择的预设（比较预设仍会重新打开比较分屏）。旧版本按预设保存的布局不再读取，升级后首次使用默认布局。

下列情况在全局布局之上临时隐藏面板，期间不保存布局，离开后恢复：没有项目时隐藏全部；非源码预览只保留文件；阅读集隐藏全部（在阅读集中查看证据会临时显示关系）；比较或参考分屏放不下时隐藏两侧，关闭分屏后恢复。

阅读区至少 320pt。每侧的最小宽度取其可见面板的最大值（关系、搜索结果 300pt，其余 180pt），但这是软约束：窗口放不下时侧区被压窄，不会为了排版放大窗口。面板最小高度：上下文 120pt、搜索结果 240pt，其余 80pt。上下文面板的头部分两行（控制、显示内容），在 300pt 的侧区中控制行会被压缩。

### 分屏阅读

文件树和标签页的右键菜单有“在右侧打开”；“视图 → 在右侧打开当前文件”（默认 `⌘\`）把当前文件的当前位置放到右侧。右侧是单文档参考栏：顶部显示路径和关闭按钮，没有标签栏，在右侧再打开别的文件直接替换。“视图 → 关闭分屏”或顶部关闭按钮收起右侧。

最后点击或移动光标的一侧是焦点一侧，顶部有一条 2pt 强调色边；它决定 Context、Outline 和高亮条计数显示哪一侧的文件，Outline 点击也跳到这一侧。在右侧 `⌘` 单击、跳到类型定义，或右侧聚焦时双击 Context 正文，都在右侧打开目标。前进/后退作用于焦点一侧，两侧各自记录历史；阅读轨迹仍是一条，不区分左右。

分屏与比较互斥：进入比较或 Focus 预设时右侧让给比较或收起，退出后恢复原来的参考栏；左侧显示非源码预览时右侧也暂时收起。分屏的文件和位置随阅读会话保存和恢复，项目外的路径不会被恢复。打开时两侧各需至少 320pt，放不下时暂时隐藏两侧面板区（关闭分屏后恢复），仍放不下则提示窗口太窄。右侧可以折叠、显示多色高亮、括号配对和块尾注解，并显示书签标记；文件内查找、作用域标题和书签切换仍只在左侧可用，关系面板结果和 Context 的右键菜单没有“在右侧打开”。

### 光标、接收者与上下文窗口

解析的是光标下的 token：`ps.get()` 的 `ps` 是接收者绑定，`get` 才是方法；`self.repo.open()` 的 `repo` 是字段/类属性，`open` 是方法。方法分派仍可使用接收者类型。这条规则同时适用于单击、定义导航和悬浮文档。

上下文窗口区分“指向的符号”与“当前显示的内容”：

- 指向值绑定时，优先显示可解析的类型，头部如 `ps: &S → S`；点击两端可切换声明与类型。
- `⌘` 单击、查看引用/调用关系、悬浮文档针对原符号；双击 Context 正文打开当前显示目标。
- “跳到类型定义”（默认 `⌃⌘J`、`⇧⌘` 单击）打开类型目标，在阅读轨迹中记为类型导航。无目标时说明原因，不随意跳到同名符号。
- 句法类型先回答，Exact `typeDefinition` 可随后增强。用户已手动切换显示端时，晚到结果不能抢回显示。等待结束、取消或空结果必须退出“解析中”。
- 语法层识别明确注解、部分包装类型、`self`/`this` 与有限的构造表达式，不是完整类型推断。原始类型留在声明；可识别的类型别名留在别名；泛型只有明确单约束时才尝试约束目标。两跳的确定性不高于其中较弱的一跳。

“符号”和“所在函数”是独立于图钉的两个跟踪模式。符号模式跟随单击与键盘光标；键盘句法查询防抖约 150ms，Exact 等同一符号停留约 400ms，单击立即请求。空白或非符号位置保留已有内容并标明保留状态，不取消已发出的当前查询。

所在函数模式选择最内层函数/方法，函数外退到所属类型；显示签名、文档和主体摘要，仅用句法信息，不发 Exact 请求。两种模式均可固定；固定后不随光标变化。跟踪模式随项目会话恢复，图钉状态不恢复。

### 悬浮文档

Rust、Python、TypeScript/TSX 支持延迟悬浮文档；也可用 `⌥` 单击或“显示符号文档”。优先使用语言服务器结果，不可用时用源码签名与 doc comment/docstring/JSDoc，并说明降级原因。无注释与缺少本地依赖源码是不同状态。

卡片可容纳签名、Markdown 和滚动正文；移进卡片可继续阅读，Esc 关闭。卡片中的符号链接尝试在应用内导航；这不等于普通 HTML/Markdown 文件预览会开放外部网络。

装有 Dash（`dash-plugin://` 有处理程序）时，卡片末尾和阅读区右键菜单各有一条"在 Dash 中查看"，用 `dash-plugin://query=…` 把符号交给 Dash 搜索，不限定 docset，第三方库的 docset 也会命中。查询词：rust-analyzer 的精确结果带有所属路径时发送 `std::sync::Mutex::lock` 这样的限定名；Pyright 和 TypeScript 的结果没有限定名，右键菜单在卡片未显示时也只有光标下的标识符，这两种情况发送标识符本身，由 Dash 的搜索结果列表消歧。未安装 Dash 时这两处入口不出现；Dash 未运行时由系统启动它。

### 多色高亮、括号与块尾注解

“高亮此名称”（默认 `⌃⌘H`，也在阅读区右键菜单）给光标处的标识符加一种颜色，再执行一次取消；右键的“高亮颜色”可以指定颜色，占用该颜色的名字随之取消。最多 6 种颜色同时存在，用满后提示，不挤掉已有的。匹配与单击同名高亮相同：同名、整词、字符串和注释之外，是词法匹配，不代表同一个符号。高亮作用于整个项目窗口的主阅读区、比较两侧和 Context 预览，随阅读会话保存，“清除阅读会话”一并清除；阅读集和悬浮卡片不显示。状态栏左侧的高亮条显示颜色编号、名字和焦点文件中的出现次数，点名字跳到下一处、`⇧` 点击跳上一处；“清除全部高亮”默认 `⌃⌥⌘H`。被单击的名字同时有高亮色时，保留高亮底色并加一圈描边。

光标紧挨 `()`、`[]`、`{}` 时给这一对括号描边，找不到另一半时只给当前括号画虚线；字符串和注释里的括号不参与。“跳到配对括号”默认 `⌃⌘M`；“选中括号内内容”默认 `⌃⇧⌘M`，重复执行逐层向外扩大。Rust 泛型尖括号与 JSX 标签不配对。

Rust、TypeScript/TSX 中，从块头到 `}` 跨 12 行以上的声明块和控制块，会在独占一行的 `}` 后淡色标注块头的简短形式（如 `‹ fn release`、`‹ match self.state`、`‹ acquire()`），最长 40 个字符。`} else {`、`} catch (e) {` 和没有块头文字的裸块不标注；Python 没有闭合符号，不标注。标注不进入文本，不能选中、复制或查找；块被折叠或换行后放不下时不显示。点击标注跳到块头并计入前进/后退，悬停显示完整块头。设置里的“标注长代码块的结尾”可以关闭。

### 概览标记

阅读区右缘、滚动条旁有一条约 12pt 宽的竖条，按显示行的比例标出全文：多色高亮按颜色分三列（6 种颜色两两共用一列），查找命中和单击同名的出现画在左列（琥珀色），书签是强调色小方块，比较时的差异用差异三色占满整宽；当前可见范围是一段浅灰底，光标所在行是一条细线。同一像素行的同类标记合并绘制。折叠区里的标记画在折叠行的位置、改成空心。点击标记跳到那一处（必要时展开折叠），点击空白或在竖条上拖动按比例滚动；悬停显示“第 N 行 · 名称”。设置里的“在滚动条旁显示概览标记”可以关闭。

竖条按行比例定位，不跟随滚动条滑块：TextKit 对还没排版的区域只估算高度，滑块位置会随排版漂移，所以竖条自带可见范围底色，点击、底色和标记始终一致。

### 搜索选项

`⇧⌘F` 显示“搜索结果”面板并聚焦输入框；该面板显示时阅读区为当前文件的命中画下划线。输入文本与条件标签表达同一个查询；点击标签可编辑或删除，“+ 添加条件”列出可用条件。一个普通词不显示标签行。语法错误停顿约 600ms 后显示位置和说明，不执行错误查询，并保留上一份结果。

| 写法 | 含义 |
| --- | --- |
| `lock await` | 每个条件都满足；默认在同一文件里出现 |
| `lock OR mutex await` | `lock` 或 `mutex` 至少一个，再同时满足 `await`；OR 比空格结合得紧 |
| `lock -test` | 排除含 `test` 的同一判断单位 |
| `"fn spawn("` | 精确短语，支持转义引号和反斜杠 |
| `/sp[a-z]+n/` | 这一项使用正则，`\/` 表示斜杠 |
| `path:src/ -path:tests/` | 读取前按项目相对路径过滤；多个包含路径取并集 |
| `in:code`、`in:comment`、`in:string`、`-in:comment` | 保留或排除指定语法区域，对包含和排除条件都生效 |
| `near:5` | 每处保留命中的前后 5 行内，其他包含条件都出现，排除条件都不出现 |
| `same:fn` | 按最内层函数或方法判断；可与 `near:` 同时使用 |

查询至少需要一个包含项；纯路径/区域过滤和纯排除不执行。第一版对 `(a OR b)` 这样的未加引号括号分组报语法错误；代码文字 `foo()`、引号短语和正则里的括号仍可使用；排除项不能用 OR 相连。只有已知限定词后的冒号有语法意义，`std::sync`、`http://`、`->`、`-=` 仍可作为普通文字。函数内闭包属于外层函数，嵌套命名函数独立；没有命名函数包围时，最外层闭包或箭头函数成为独立单位。`same:fn` 不返回任何函数单位之外的命中。

大小写开关作用于全部项；全词和整体正则开关只作用于普通词，不改变引号短语和斜杠正则的含义。全词边界采用 Unicode 标识符字符及 `_`，TypeScript/TSX 另加 `$`。从阅读区选中文字带入搜索，或向空输入框粘贴含空格的文本时，自动加引号作为精确短语；手动输入多个词则表示同时满足。路径 glob 支持 `*`、`**`、`?`、`{a,b}`；结尾 `/` 表示目录，无 `/` 的模式可匹配任意层级名称。

搜索结果面板最小 240pt 高，位置和高度随面板布局保存。文件分组标题为展开三角预留独立空间，覆盖说明显示 Rust/Python/TypeScript 等正式名称。结果按文件排列，符号列显示函数/方法或所在类型、impl、模块；连续同一符号用竖线延续。包含条件用四色小块和同色下划线区分，颜色不占用阅读区的高亮底色。多条件、OR 或带 `near`/`same:fn` 的结果按行合并，保留每个条件的命中范围；单个普通词、短语或正则在文件范围内逐处返回，添加路径、区域或排除过滤不改变这一计数方式。

单击结果在预览标签中选中并闪烁命中，焦点留在列表；方向键继续浏览，回车或双击进入阅读区。`⌥⌘G` / `⇧⌥⌘G` 在任意焦点下跳下一处/上一处，文件内查找 `⌘G` 不变。Esc 关闭当前提示，或将焦点还给阅读区，面板保留；面板的 `×` 或“显示/隐藏搜索结果”才关闭它。菜单命令均可在快捷键设置中重绑。

刷新或切换快照会重搜，旧结果标为过期且不能跳转，新结果到达后替换。刷新按文件路径、内容身份和命中字节范围恢复原选中项；尚未到达对应批次或命中已消失时清选，不改选第一条。阅读区的选中位置与滚动锚点分别保存，仅在内容身份一致时原样恢复；没有内容身份的搜索结果不能导航。仅修改查询文字时保留同一快照的旧结果可点击，直到新批次替换。每项目保存最近 20 条明确采用的查询及三个开关状态：回车、点击结果、使用历史、关闭搜索结果面板或关闭窗口/退出时记录；搜索防抖和自动会话保存不把输入中的半截查询加入历史。点击尚未替换的旧结果记录该结果对应的查询。历史可用按钮或输入框行首的 ↑ 调出；最后查询随会话恢复，面板位置随全局布局恢复，索引就绪后自动重搜。“清除阅读会话”一并清除查询历史。会话格式升至 v5，仍能读取 v4；较旧应用不会覆盖它不认识的新格式。

面板底部说明搜索语言、源文件数、路径过滤数、项目规则排除路径数、未搜索的非源码数及正则跳过数；零项省略。包含条件独立受每文件 200 处、每语言搜索会话总计 5,000 处的上限；排除条件只记录文件、行或函数内是否存在，不消耗这些数量限额。扫描仍受 5 秒预算和取消约束；无法确认排除项时不发布该文件的结果，并标明不完整。组合判断也检查取消及时间预算。不完整时显示截断条件和文件标记。列表最多展示 2,000 处，超过时说明。区域取命中起点，和阅读区高亮共用语法分类；这是句法信息，不代表运行时语义。非源码文件仍不参与项目搜索。

输入有焦点且空白、没有结果或结果过多时，停顿约 2 秒后显示建议。可追加的建议以灰字每约 28ms 一字呈现，Tab 接受；其他建议放在输入框下的气泡中，约 180ms 淡入并上移 6pt。Esc 或继续输入关闭提示，同次搜索关闭后不再弹；成功用过的语法在应用级记住，不再推荐。系统“减弱动态效果”开启时直接显示。设置“显示查询提示”可关闭，“恢复阅读器默认值”恢复为开启；`?` 可随时查看完整语法。

命令行 `codeinsight search '<查询>'` 使用相同解析与求值，支持 `--whole-word`；负条件可位于查询开头，查询与 CLI 选项重名时用 `--` 分隔；语法错误在索引前显示可读原因及 UTF-16 位置。文本/JSON 包含条件、符号、覆盖和截断信息。`--repeat N` 在索引一次后重复搜索，结果输出一次，计时另写 stderr。字段与性能复现见[开发说明](development.md#性能复现)。

文件内查找（`⌘F`）仍是单模式搜索，也支持全词；上述组合语法仅用于项目搜索。关系面板的引用查询不受影响。

## 关系、证据与阅读记录

Relations 是静态源码候选关系，不承诺运行时完整调用图。当前是一层结果列表，激活结果换根；前进/后退用于继续探索，不递归展开无限深树。右键关系命令更新关系面板，固定的 Context 不被覆盖。

结果分别描述候选确定性、调用分派、来源、结果集完整程度和分析环境。Verified 表示 provider 给过正向验证结果；Inferred 表示源码推断；Unresolved 表示未解析。Safe 模式限制不能抹掉已有正向结果，Exact 没返回一个候选也不能当作证明它错误。可比较且不同的目标才形成冲突，被修正候选保留在证据视图。

阅读轨迹记录显式语义导航及分支，滚动和标签切换不生成语义边。导航发生时的冻结说明与当前分析说明分开。恢复旧会话不能用新查询悄悄替换冻结证据。

阅读集来自 Freeze Results 或 Freeze Path，保存连续源码片段及其出处、快照、角色和冻结说明。它是可恢复的阅读材料，不是可任意编辑的整理列表。

书签绑定精确快照内容。工作区变化显示 Drifted，必须明确 Re-anchor；位置、文件或 revision 不可用时不静默跳转。最多 32 条记录，每条纯文本笔记最多 2 KiB，原子保存。依赖文件、比较、阅读集和 mini reader 不提供书签；不实现跨 commit 符号自动映射。

## 字体、快捷键与语言

Light、Dark、SI Classic 共用语义主题值。代码字体选择本机等宽字体，编程连字可为 Font Default、On、Off。缺失字体回退系统字体但保留用户选择，Refresh Fonts 用于重新发现字体；产品不分发第三方字体。

主 Reader、比较、Context、阅读集和设置预览使用同一代码字体策略。字体/颜色变化应保持源码、选区和折叠；超过 8,000 行或源行超过 64 KiB 时避免同步全文精确重排，不保证巨行的精确像素锚点。

Settings → 快捷键提供搜索、按键搜索、录制、冲突替换及恢复默认。菜单命令与阅读器鼠标手势可配置；系统保留组合锁定，面板内方向键/回车/Esc 只读显示。覆盖项只保存与默认表的差异，更新菜单、工具栏和命令面板；关闭设置、切页或切窗必须结束录制，按键搜索捕获一次即结束。当前只有默认方案，不提供导入导出。

产品界面支持英文和简体中文，跟随系统应用语言设置，其他语言回退英文。源码、路径、工具名、用户笔记、稳定存储键和原始工具诊断不翻译。新冻结的轨迹/阅读集保存双语说明，旧版纯文本证据保持原文。

## 非源码预览

Markdown 使用只读富文本，HTML 使用受控 WKWebView（关闭 JavaScript、网络及本地子资源），图片和 PDF 使用只读预览，其余严格 UTF-8 文本可选择复制；未知二进制明确为不支持。

Markdown/HTML 的项目内链接可导航，前进/后退跨预览可用，commit 标签读取对应快照字节。非源码预览不提供符号大纲、折叠、关系、书签、比较、Reading Height 或搜索控件；不打开外链或内联本地资源。
